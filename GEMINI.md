# Инструкции для Gemini (krugok-app)

## Описание проекта
Этот проект — Telegram Mini App, написанный на Python с использованием фреймворка Django. Это система управления задачами и проектами ("кружок"), где пользователи могут взаимодействовать с платформой через интерфейс, встроенный в Telegram.

## Технологический стек
*   **Backend:** Python, Django.
*   **Frontend:** HTML, серверный рендеринг через стандартные шаблоны Django (Django Templates).
*   **Авторизация:** Кастомная авторизация через Telegram (логика описана в `core/telegram_auth.py`).

## Архитектура и структура
*   Основная бизнес-логика, маршруты и модели находятся в приложении `core`[cite: 1].
*   Настройки проекта, WSGI/ASGI и корневые URL лежат в директории `config`[cite: 1].
*   Проект придерживается классического паттерна: `models.py` -> `forms.py` -> `views.py` -> `templates`[cite: 1].
*   Все UI-компоненты разделены по папкам сущностей внутри `core/templates/core/` (например, `projects`, `stages`, `tasks`)[cite: 1].

## Ключевые сущности (База данных)
Проект работает со следующими основными объектами[cite: 1]:
*   `TelegramUser`: Пользователи с привязкой к Telegram (включает поля `is_premium` и `language_code`)[cite: 1].
*   `Project`: Основная сущность проектов[cite: 1].
*   `Stage`: Этапы выполнения внутри проектов[cite: 1].
*   `Task`: Конкретные задачи, привязанные к этапам (`task_stage`)[cite: 1].
*   `Comment`: Комментарии пользователей к задачам[cite: 1].
*   `Discussion`: Обсуждения[cite: 1].

## Правила написания кода для Агента
1.  **Стиль:** Пиши чистый, лаконичный Python-код. Обязательно используй Type Hints (тайп-хинты) во всех новых функциях и методах.
2.  **Шаблоны:** При добавлении или изменении UI используй исключительно Django Templates[cite: 1]. Структурируй код, используя компоненты (например, `card.html`, `list.html`, `detail.html`, `form.html`)[cite: 1].
3.  **Авторизация:** При написании views всегда помни, что пользователи авторизуются через механизмы Telegram (`telegram_auth.py`)[cite: 1]. Учитывай это при проверке прав доступа к проектам и задачам.
4.  **Фронтенд:** Не предлагай использовать сторонние SPA-фреймворки (React, Vue и т.д.). Мы рендерим весь HTML на сервере[cite: 1].
5.  **Миграции:** Никогда не правь файлы миграций в `core/migrations/` вручную[cite: 1]. Если вносишь изменения в `models.py`[cite: 1], просто напиши в ответе команду `python manage.py makemigrations`[cite: 1].
